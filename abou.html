Technical Terms

HTML (HyperText Markup Language)
HTML is a markup language used to structure content on a webpage, including headings, paragraphs, images, and links.
CSS (Cascading Style Sheets)
CSS is used to style and design webpages by controlling colors, fonts, spacing, and layouts.
JavaScript
JavaScript is a programming language used to add interactivity and dynamic functionality to websites.
Responsive Design
Responsive design is a web development approach that allows websites to adapt to different screen sizes, such as phones, tablets, and computers.

About My Project

Project Description

My project is a personal portfolio website developed using HTML and CSS. HTML is used to create the structure and content of the website, while CSS is used to style and improve its appearance.

The project uses technical concepts such as HTML elements, CSS selectors, navigation links, responsive design, and web layout. These technologies help make the website organized, attractive, and easy to navigate.

Technical Terms

  • HTML - Defines the structure of the webpage.
  • CSS - Controls the style and appearance.
  • CSS Selectors - Select elements to be styled.
  • Navigation Links - Connect different webpages.
  • Responsive Design - Makes the website adapt to different screen sizes.
