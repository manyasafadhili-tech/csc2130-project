Project Description

My project is a personal portfolio website designed to showcase my skills, education, projects, and contact information as a Computer Science student pursuing Software Engineering. The website is developed using HTML, CSS, and JavaScript to create a structured, responsive, and interactive user experience.

The frontend uses HTML for the structure of web pages, CSS for styling and layout, and JavaScript for adding interactivity. The project can also be extended with PHP for backend processing and MySQL for storing and managing data.

The main purpose of the project is to provide an online platform where visitors can learn about my technical skills, view my projects, and contact me for professional or academic purposes.
