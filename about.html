About the work

A student web development project

This project demonstrates foundational HTML5 page structure, semantic elements, navigation, tables, and media. It is a static front-end learning project; PHP, MySQL, and JavaScript are not currently implemented.

Mission

To build clear, accessible web pages while developing practical skills in modern web technologies.

Vision

To continue learning and create useful digital experiences that are easy for people to explore.

Technologies demonstrated

  • HTML5: structures page content and provides semantic meaning.
  • CSS3: styles layouts and supports responsive presentation.
  • SVG: provides lightweight, scalable project illustrations.
